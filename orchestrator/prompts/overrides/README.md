# Правки к промптам, которые потребовал оркестратор

Эти файлы дописываются к промптам из `vypusk-1-wfrp-desyatina.md` на старте
прогона. Каждый — правка, которую надо вернуть в документ проекта. Загружаются
только `*.txt`, этот README в промпты не попадает.

| Файл | Что добавляет | Зачем |
|---|---|---|
| `gm/01-теги-режима.txt` | Тег `[РЕЖИМ: РАЗГОВОР\|ДЕЙСТВИЕ]` в конце каждой сцены плюс напоминание, что разговорные сцены не редкость | Режимного переключателя в промпте мастера не было вообще, а на нём держится вся маршрутизация. На пробном прогоне Sonnet пять кругов подряд держал ДЕЙСТВИЕ, и ротация простаивала |
| `gm/02-финал.txt` | Тег `[ФИНАЛ]` | Иначе скрипт не отличает развязку от обычной сцены и досиживает до предела кругов |
| `gm/03-проверки.txt` | Жёсткий формат строки проверки, требование звать проверку на всё сомнительное, порядок для персонажей мира | Формат в документе описан, но без запрета на встречные проверки в одну строку и без объяснения, что результат приходит уже посчитанным. Haiku за пять кругов не запросил ни одной проверки. Броски за NPC требовали отдельного правила |
| `gm/04-личные-блоки.txt` | Правила блоков «ТОЛЬКО ДЛЯ» и вид входящих сообщений | Парсер режет реплику по заголовку; без правила «личное в конце» публичная часть после личного блока пропала бы у троих |
| `gm/05-темп.txt` | Счётчик круга и обязанность свести линии к двадцатому, закончить к тридцатому | Без счётчика мастер растянул ваншот до шестидесяти кругов |
| `gm/06-выбытие.txt` | Теги `[ВЫБЫЛ]` и `[ВЕРНУЛСЯ]`, определение выбытия | Выбывший игрок несколько кругов подряд повторял одну реплику; заодно оговорено, что слышащий и видящий персонаж не выбыл |
| `gm/07-бой.txt` | Точный формат строки `АТАКА`, список слов для оружия, что присылает посредник | Документ описывает бой словами, но парсеру нужен жёсткий формат и словарь оружия |
| `player/03-раны.txt` | Своё состояние, чужое только со стороны, ответ ДА/НЕТ на вопрос о Судьбе | Скрипт спрашивает игрока лично; без формата ответа решение не разобрать |
| `player/01-тайный-ход.txt` | `ТАЙНО` — первое слово всего хода | В документе сказано «начни строку», но разрезать ход пополам скрипт не может, не нарушив правило «реплики не редактируем» |
| `player/02-входящие.txt` | Расшифровка префиксов посредника | Игрок должен понимать, кто с ним говорит, и не отвечать посреднику |

Отдельно от промптов: дефолт режима в `config.json` переведён с `ДЕЙСТВИЕ` на
`РАЗГОВОР`, и текст в `gm/01-теги-режима.txt` этому соответствует.

Ещё отдельно: в `config.json` появился блок `персонажи_мира` —
характеристики Гретель, Йорга, Мунка, сержанта, патрульного и твари. Цифры мои,
как и цифры игроков в документе. Без них броски за персонажей мира катились по
заглушечной базе 30.

Правки в самих промптах документа не сделаны нарочно: документ — продакшн-пакет
для ручного прогона, он живёт своей жизнью. Слить обратно после репетиции.
