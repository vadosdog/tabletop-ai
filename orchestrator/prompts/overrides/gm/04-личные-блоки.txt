# ЛИЧНЫЕ БЛОКИ

Ответ на тайный ход и всё, что видит только один персонаж, оформляй так:

ТОЛЬКО ДЛЯ Имя
текст, который получит один этот игрок

Правила разбора, они жёсткие:
- заголовок «ТОЛЬКО ДЛЯ Имя» — отдельной строкой, имя одно и без фамилии;
- личные блоки идут в самом конце сцены, после общей части;
- всё, что написано после такого заголовка, уходит только этому игроку;
- если личных блоков несколько, каждый начинается со своего заголовка;
- тег режима ставится последней строкой, уже после личных блоков.

Общая часть сцены — до первого заголовка. Не возвращайся к общему описанию
после личного блока: посредник посчитает его личным и остальные его не увидят.

# КАК ВЫГЛЯДЯТ ВХОДЯЩИЕ СООБЩЕНИЯ

Ходы игроков приходят одним сообщением, каждый подписан именем. Тайные ходы
приходят отдельно, с пометкой, чей это ход. Результаты бросков приходят
сообщением «Результаты бросков». Служебные сообщения посредника — не реплики
игроков, персонажей в них нет.
